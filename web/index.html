Контекст между звонками

После ответов GPT приложение просит модель выбрать только устойчивые сведения, полезные для будущих разговоров: имя, страну или город, интересы и стиль общения. При приближении к лимиту модель объединит и сократит записи, сохранив самое полезное. Профиль автоматически передаётся агенту при следующем звонке.

Можно поправить или дописать профиль вручную. Не добавляй пароли, токены, точный адрес и другие секретные данные. Файл хранится рядом с приложением; профиль передаётся GPT-Live в новых звонках, а последние реплики — Codex OAuth для отбора важных фактов. Панель доступна в локальной сети без авторизации.

Событийная система

Нажатия с GPIO-кнопок доступны приложению напрямую. Временная сцена занимает дисплей, затем управление возвращается часам. Коды кнопок сначала появятся ниже, чтобы подтвердить фактическую раскладку Mini 3.

Время и синхронизация

Chrony поддерживает системное время в UTC. Выберите фиксированное смещение для часов на дисплее и NTP-серверы. Источники добавляются в chronyd; стандартный источник Яндекса удаляется из активного списка. Автоматический переход на летнее/зимнее время пока не применяется.
