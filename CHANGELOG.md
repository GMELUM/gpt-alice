# Changelog

## Unreleased

- Bluetooth-жесты по трём сенсорным кнопкам для next/previous; центральная кнопка переключает play/pause при подключённом Bluetooth.
- Звук кнопок фиксирован на 10% независимо от общей громкости и звонка; шаг регулировки громкости остаётся 5 пунктов.
- Исправлены AVRCP-команды для BlueZ: `player.next` и другие команды вместо записи с пробелом.

- Telegram: настройки токена бота и чата в панели, проверочное сообщение, голосовые команды отправки текста, ссылок и картинок по URL.
- SQLite вместо отдельных файлов настроек, профиля, расписаний и токенов; автоматическая миграция с сохранением авторизации.
- XChaCha20-Poly1305 для содержимого записей, отдельный случайный ключ устройства и отказ от сброса данных при неверном ключе.

- Исправлена потеря следующего дубля из-за таймаута предыдущей записи микрофона.
- Таймеры и будильники подают локальный сигнал даже без активного GPT-Live звонка.
- Нефатальные ошибки аудиопомощника не останавливают мониторинг; фатальные освобождают сессию и процесс.
- Сохранение времени/NTP больше не сбрасывает сохранённые громкость и яркость.
- Сериализованы обновление OAuth и выход; отменённый device flow не восстанавливает токены.
- Статус Bluetooth читается из фонового кэша, системные команды ограничены таймаутами.
- Журнал Linux ограничен двумя файлами по 2 МиБ; регулярные PCM-метрики выключены по умолчанию.
- VPN-watchdog принимает комментарии после Endpoint, как и валидатор конфигурации.

## v0.3.0 — 2026-10-31

- Перебивание голосового ответа: server-side VAD останавливает текущую реплику, когда пользователь начинает говорить, а аудиомикшер очищает уже поставленный в очередь голос.
- Исправлена совместимость настройки VAD с GPT-Live Codex endpoint: неподдерживаемое поле `session.type` больше не отклоняет обновление сессии.

## v0.2.0 — 2026-10-29

- Общий Rust-микшер для GPT-Live, Bluetooth и звуков кнопок; отдельный ARMHF `audio-sink` единолично открывает аппаратный ALSA PCM через mmap.
- Восстановление playback при смене потока микрофона: при запуске звонка динамик больше не должен оставаться без звука.
- Bluetooth A2DP-приёмник, AVRCP-управление воспроизведением и плавное приглушение музыки во время ответа GPT.
- Несколько таймеров и будильников, продление таймеров, сохранение расписания и голосовое управление.
- Контроль простоя звонка с режимом ожидания, отображение таймера в веб-панели и случайные короткие приветствия.
- Подготовка wake-word: модели рядом с бинарниками, переключатель запуска звонка и запись обучающих примеров через микрофоны колонки.
- Скрипты подготовки и обучения корпуса с атрибуцией фоновых записей. Пилотная модель «Алиса» экспериментальная и отключена по умолчанию.

В архиве релиза нужны все три бинарника: `gpt-alice`, `gpt-live-host`, `audio-sink`. Установите `audio-sink` в `/data/opt/gpt-alice/tools/`, остальные бинарники и каталог `wakeword` — в `/data/opt/gpt-alice/`. При обновлении сохраните собственные OAuth-токены, настройки, расписание и записи голоса.
